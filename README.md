# 말차 or 녹차

간이 분광광도계(RGB LED)와 닌히드린 반응지 RGB로 말차와 녹차를 구별하는 웹 앱입니다.
경북과학고등학교 STEAM 클럽 연구 「제주 녹차 및 말차의 생화학적 성분 차이에 기반한 현장 적용형 판별 키트 개발」의 결과물입니다.

## 기능
- **분광광도계 판별**: Web Serial로 간이 분광광도계(아두이노)에 연결해 RED 620 / GREEN 520 / BLUE 450 nm 흡광도를 측정하고 말차·녹차를 판정합니다. 장비 없이 흡광도 값을 직접 입력할 수도 있습니다.
- **반응지 RGB 판별**: 닌히드린 반응지 사진을 올리고 발색 부분을 누르면 RGB를 읽어 판정합니다.
- **판별 기준**: 두 방법의 기준과 근거 데이터를 정리했습니다.

## 판별 기준 요약
| 방법 | 주 기준 | 보조 기준 |
|---|---|---|
| 분광광도계 | 평균 흡광도 Ā ≥ 0.39 → 말차 (0.34~0.44 경계 구간) | 파장별 투표, 엽록소 지수 (A<sub>R</sub>+A<sub>B</sub>)/2/A<sub>G</sub> ≥ 1.21 |
| 반응지 RGB | G ≤ 70 → 말차 (60~77 경계 구간) | 밝기 Y ≤ 81, 평균색 거리 |

## 사용 환경
- 분광광도계 연결은 PC의 Chrome 또는 Edge(89 이상)에서만 됩니다(Web Serial).
- 시료 프로토콜: 가루 3 g + 증류수 200 mL → 거름종이 여과 → 3000 rpm 5분 원심분리.
